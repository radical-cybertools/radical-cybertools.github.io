Basic User Guide

1 RADICAL-Pilot Setup

Documentation: http://radicalpilot.readthedocs.org/en/stable/machconf.html#preconfigured-resources

First, we will import the necessary dependencies.

import os, sys
import radical.pilot as rp
print(rp.version)

2. Local Pilot Example

This example shows how to execute simple tasks using a Pilot-Job.

2.1 Create a new Session and Managers.

session = rp.Session()
pmgr = rp.PilotManager(session=session)
tmgr = rp.TaskManager (session=session,scheduler=rp.SCHED_ROUND_ROBIN)
print ("Session id: %s \n \
 Pilot Manager: %s \n \
 Task Manager: %s" % (session.uid, pmgr.uid, tmgr.uid))

2.2 Submit Pilot and add to Task Manager

Create a description of the Pilot, which specifies its target resource, size and runtime.

pdesc = rp.PilotDescription()
pdesc.resource = "local.localhost"
pdesc.runtime  = 10 # minutes
pdesc.cores    = 2
pilot = pmgr.submit_pilots(pdesc)
tmgr.add_pilots(pilot)

The tmgr.add_pilot(pilot) binds a Pilot to a Task Manager. This informs the Task Manager that the resources of the Pilot can be used for exeuction of Tasks. Multiple Pilots can be bound to a Task Manager, and later be removed via tmgr.remove_pilot(). The Task Manager will schedule incoming Tasks across all available Pilots.

print("uid: ", pilot.uid)
print("resource: ", pilot.resource)
print("sandbox: ", pilot.sandbox)
print("state: ", pilot.state)

2.3 Submit Tasks

Create a description of the Task, which specifies the details of the task to be executed.

td_1 = rp.TaskDescription()
td_1.environment = {'TASK_NO': 1}
td_1.executable  = "/bin/echo"
td_1.arguments   = ['I am Task number $TASK_NO']
td_1.cores       = 1

td_2 = rp.TaskDescription()
td_2.environment = {'TASK_NO': 2}
td_2.executable  = "/bin/echo"
td_2.arguments   = ['I am Task number $TASK_NO']
td_2.cores       = 1

Submit the previously created Task descriptions to the Task Manager. This will trigger the selected scheduler (in this case the Round-Robin scheduler) to start assigning Tasks to the Pilots.

print ("Submit Tasks to Task Manager ...")
tasks = tmgr.submit_tasks([td_1, td_2])
print ("Waiting for Tasks to complete ...")
tmgr.wait_tasks()
print ("All Tasks completed successfully!")

Inspect the output of the Tasks

print (tasks[0].stdout)
print (tasks[1].stdout)

2.6 Close Session

The session must always be closed before exiting: this will tear down the Pilots, which would otherwise continue to consume resources until their specified runtime is up.

session.close()
